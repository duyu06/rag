# 星瀚科技员工手册（演示数据）

版本：V2.0  
适用范围：全体员工  
归属知识库：HR 知识库

## 1. 试用期

普通岗位试用期为 3 个月。管理岗位与关键技术岗位试用期可根据劳动合同约定执行，但不得超过法律规定上限。

## 2. 年假

员工连续工作满 1 年后享受带薪年假。年假申请原则上应至少提前 3 个工作日提交，并由直属负责人审批。

## 3. 调薪

年度调薪窗口通常安排在每年 4 月。调薪结果综合考虑绩效等级、岗位价值、市场薪酬水平与公司经营情况，不承诺固定调薪比例。

## 4. 保密要求

员工不得将客户资料、薪酬数据、内部财务信息、未公开产品规划以及账号密钥等信息对外披露。

> 本文件仅用于 yaoke 企业 RAG 演示，不代表任何真实公司的制度。
