# 星瀚终端设备安装与部署指南（演示数据）

版本：V1.2  
归属知识库：产品知识库

## 1. 安装前检查

确认设备型号、电源规格、网线和安装位置。X200 应避免安装在完全密闭且无散热条件的金属箱体内。

## 2. 网络接入

首次部署推荐使用有线网络。设备获取 DHCP 地址后，可通过同网段发现工具定位设备。

## 3. 初始配置

本地管理页面默认使用 HTTPS 8443 端口。首次登录必须修改默认密码，再配置 NTP、DNS 和业务服务器地址。

## 4. 上线验证

至少验证网络连通、时间同步、业务心跳、数据上报和远程日志五项。五项全部通过后才能标记为“已交付”。
