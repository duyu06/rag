# 星瀚科技考勤与加班管理办法（演示数据）

版本：V2.2  
归属知识库：HR 知识库

## 1. 工作时间

标准工作日为周一至周五。弹性到岗时段为 8:30 至 9:30，员工应在 9:30 前完成打卡。

## 2. 迟到与异常

9:30 后打卡记为迟到。因客户现场、外出拜访或系统故障导致异常打卡，应在 2 个工作日内提交异常说明。

## 3. 加班

工作日预计加班超过 2 小时，或周末安排加班，应提前在 OA 发起加班申请并由直属负责人批准。未审批的自愿延时不作为调休依据。

## 4. 调休

已审批加班形成的调休原则上应在 3 个月内使用，逾期需 HR 复核。

> 本文件仅用于 NexusKB 演示。
