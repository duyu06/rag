# 星瀚科技信息安全管理规范（演示数据）

版本：V1.4  
归属知识库：公共制度

## 1. 账号与密码

公司业务系统密码最长使用周期为 90 天。财务、管理员和生产环境账号必须启用多因素认证（MFA），禁止多人共用个人账号。

## 2. 敏感文件

客户名单、合同、薪酬、财务报表、API Key、生产密钥属于敏感信息。敏感文件不得上传到个人网盘或通过私人邮箱转发。

## 3. 外接设备

员工使用 U 盘等可移动存储设备拷贝业务数据前，应取得直属负责人批准；涉及客户隐私数据时还需信息安全负责人批准。

## 4. 账号离职回收

员工离职后，IT 应在最后工作日结束前关闭业务系统账号并回收 VPN、代码仓库和云平台权限。

> 本文件仅用于 NexusKB 演示。
